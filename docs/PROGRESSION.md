# Progression

Every tier introduces a change in how you play, not only a bigger number.

| Unlock | Cost | Effect on play |
|---|---|---|
| Deep Satchel 1-3 | 150 / 500 / 1500 | More charges: enables multi-charge setups |
| Fat Fuse 1-3 | 250 / 800 / 2500 | Wider Blasting Cap reach (+0.5 cells per level) |
| Momentum Coil 1-2 | 600 / 2000 | Refund threshold 10 > 8 > 6 |
| Shaft Charge | 400 | New blast shape (column); combos with Lensglass (row) |
| Seismograph | 900 | Full-chain preview |
| Stratum 2: Prism Veins | 1200 | Lensglass beams and Dreadgeode hazards |
| Stratum 3: Ember Hollows | 4000 | Slowburn delayed-fuse crystals (timing becomes part of planning) |
| Stratum 4: Echo Caverns | 12000 | Echostone relays: chains can jump across the grid |
